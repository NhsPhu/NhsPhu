### 🛒 Omni Marketplace — *Dự án trọng tâm*

> Nền tảng thương mại điện tử đa nhà bán **(B2B2C)** theo mô hình Shopee/Tiki, xây dựng từ đầu với kiến trúc **Modular Monolith + Hexagonal Architecture**.

- 🏗️ **Backend:** Java 17 · Spring Boot 3 · Hexagonal Architecture · Flyway Migration
- 🌐 **Frontend:** Next.js 16 (App Router) · React 19 · TypeScript 5 · TailwindCSS 4 · Ant Design
- ⚡ **Event-Driven:** RabbitMQ — xử lý async: đặt hàng, thanh toán, thông báo
- 🔍 **Search:** Elasticsearch 8 — full-text search, filter đa chiều, real-time sync
- 🔴 **Cache + Rate Limit:** Redis · Bucket4j — giảm ~60% query DB
- 💳 **Integrations:** VNPay (thanh toán) · GHN (vận chuyển) · Cloudinary (media)
- 📊 **Observability:** Prometheus · Grafana · Zipkin (tracing) · Sentry · k6 (load test)
- 🔄 **CI/CD:** GitHub Actions — auto build, test, deploy khi merge vào main

---

### 🎬 Movie Streaming System

> Hệ thống phát video **Adaptive Streaming (HLS)** đa nền tảng theo kiến trúc **Microservices**.

- 🏗️ **Backend:** Java Spring Boot · Spring Data JPA · Spring Security
- 📱 **Mobile:** Kotlin Android · MVVM · ExoPlayer (HLS adaptive player)
- 🌐 **Web:** React 18 · Video.js
- 🤖 **AI Service:** Python FastAPI — gợi ý phim bằng **Collaborative Filtering (Scikit-learn)**
- 🎞️ **Media:** FFmpeg — transcode tự động 4 chất lượng (1080p → 360p), HLS segments
- 🔄 **Cross-Platform Sync:** Đồng bộ tiến độ xem real-time giữa Web & Android
- 🐳 **DevOps:** Docker · Docker Compose

---

### 📊 AI Sales Analysis Dashboard

> Hệ thống **Business Intelligence** tự động hóa phân tích dữ liệu bán hàng.

- 📥 **ETL Pipeline:** Tự động trích xuất và chuẩn hóa dữ liệu từ CSV/JSON
- 📈 **Visualization:** Dashboard KPI tương tác với Plotly
- 🤖 **AI:** Tích hợp Groq API — truy vấn dữ liệu bằng ngôn ngữ tự nhiên
- 🔮 **Forecast:** Dự báo xu hướng doanh thu với **Facebook Prophet** (MAPE < 8%)
